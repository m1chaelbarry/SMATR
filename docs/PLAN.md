# SMATR: zaakceptowany plan realizacji

Strona statyczna Astro + MDX + TypeScript, React dla sześciu prowadzonych symulatorów; GitHub Pages, druk HTML, bez osobnego PDF i bez edytorów obwodów.

1. Pełny podręcznik: cztery części, mapa wymagań, minimum 32 zadania z podpowiedziami i uzasadnionymi rozwiązaniami, przykład 100–120–100 mm w trzech technikach, słownik, przygotowanie i errata.
2. Kontrola treści przed symulatorami: tablice prawdy, NAND, geometria, pełne ślady cyklu, dostępne TTL, parametry starego LOGO.
3. Symulatory kolejno: stanowisko, zderzaki, przekaźniki, bramki, SR/RS, panel LOGO.
4. Weryfikacja modeli Vitest, interfejsu Playwright, mobile/desktop/druk/klawiatura/reduced motion oraz produkcyjny base path.
5. Dokumentacja uruchomienia i raport; przygotowanie workflow Pages, bez publikacji ani udostępniania źródłowych PDF.

Źródła: lokalne 1smatr.pdf (17 stron), 2smatr.pdf (12 stron), 3smatr.pdf (20 stron); dwa teksty pomocnicze. Numeracja źródeł to strony pliku PDF, nie numery nadrukowane w skanach. Dodatkowa dokumentacja Siemens 1997 służy do rozstrzygnięcia potwierdzonych literówek, bez poszerzania wyposażenia laboratorium.
